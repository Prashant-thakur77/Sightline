# @sightline/paypal: notes against PayPal's live docs

Checked 2026-11-09 against the live OpenAPI schemas (`developer.paypal.com/api/<api>/schema.json`) for Orders v2,
Payments v2, Payment Method Tokens v3, Disputes v1, Webhooks v1, Shipment Tracking v1 and Transaction Search v1,
plus the guides they link to. Where the plan differs, live docs won.

## Useful sandbox facts

- Dispute docs create the buyer transaction by "Send and Request" from the sandbox personal account and copy its
  Transaction ID. `validate-eligibility` (limited release, schema unpublished) is described as returning the buyer
  transaction id for a seller transaction.
- Escalation day by amount: 5.00-5.99 day 5, 9.00-9.99 day 9, 11.00+ day 11.
- `ACCELERATED_RESPONSE_ENABLED` in `evidences[].notes` on create turns on Accelerated Response (INR and SNAD only).
- `POST /v2/customer-support/process-chargeback` simulates a chargeback (not wrapped; use `client.request`).
- Simulated webhook events carry `webhook_id: "WEBHOOK_ID"` and never verify; use real transactions or resend.
- Transactions take up to 3 hours to appear in Transaction Search; 31-day window; 3-year history.
- Buyer-present vault payments need risk data (`PayPal-Client-Metadata-Id`); `orders.create` takes `clientMetadataId`.
