# S3: Shipment tracking in the sandbox

## Question

Which tracking endpoint works in the sandbox for an Orders v2 capture: `POST /v2/checkout/orders/{id}/track`
(the path live docs give for Orders v2) or `POST /v1/shipping/trackers-batch` (Add Tracking API)? Can we read
trackers back and set a delivered status? Does any webhook fire for tracking or delivery?

## What we ran

`packages/db/node_modules/.bin/tsx packages/paypal/spikes/run.ts s3-tracking` (uses the captured order from the
last `s2-vault` run; pass `--order=ID` to use another).

1. Added a tracker with each strategy (different tracking numbers so they do not collide).
2. Read trackers back with `GET /v1/shipping/trackers?transaction_id=` and from the order's `shipping.trackers`.
3. Tried `PUT /v1/shipping/trackers/{id}` with status `DELIVERED` (Orders v2 trackers only allow SHIPPED or CANCELLED).
4. Listed webhook event types and filtered for tracking, shipping or delivery events.
